    Cek arsitektur Android kamu

    1. Buka Settings → About phone, lihat Processor. Snapdragon, Dimensity, Exynos, Helio dan Tensor hampir selalu ARM.
    2. Pasang aplikasi CPU-Z atau Device Info HW, lalu lihat Architecture / Supported ABIs.
    3. Pengguna Termux: jalankan uname -m. aarch64 = ARM64, armv7l atau armv8l = ARMv7, x86_64 = x86_64.

    Sebuah CPU 64-bit bisa saja menjalankan Android 32-bit. Jika hasilnya armv8l atau daftar ABI hanya berisi armeabi-v7a, pilih ARMv7.
